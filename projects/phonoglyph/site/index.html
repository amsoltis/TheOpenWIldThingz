How can a font do that?

A font isn't just shapes — modern font files can run a small program while your text is being laid out. People have hidden entire QR-code generators and a playable video game inside single font files. Phonotype uses that same machinery for a new trick: English pronunciation.

01

Fonts can compute

OpenType fonts carry substitution tables that swap and combine glyphs as text is shaped. That mechanism is powerful enough to do real logic.

02

Pronunciation, baked in

~2,000 common words (plus the nasty irregulars — through, colonel, yacht) and a set of spelling→sound rules live inside the font as substitutions.

03

Only the shapes change

It swaps glyphs at render time — the underlying text stays English. So select, copy, and paste, and you get the original words back, untouched.

Why it's new

Plenty of tools convert English to a pronunciation guide — but they're websites, or fonts that only display symbols you already typed. None of them compute the pronunciation inside the font itself. As far as I can tell, this is the first that does.

The honest catch

Because it's a genuine experiment, not a magic wand:

It's approximate. English is full of words spelled the same but said differently (read, lead, live) — no spelling-based system can resolve those without understanding meaning. Phonotype picks each word's most common pronunciation. It's a reading aid, not a dictionary.
It runs in browsers, not everywhere. The in-font computation works in Chrome, Firefox, and Safari (and this page). Some native apps use a text engine that skips it.

The 🔊 button is your browser's own voice reading the original English — a separate convenience. The font itself is silent; it changes how words look, not sound.
