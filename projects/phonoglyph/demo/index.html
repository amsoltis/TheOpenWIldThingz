Phonoglyph preview

A font that respells English phonetically inside itself. This page is a JavaScript preview of the font's logic — the real artifact does this in GSUB, and copy-paste returns the original text. Type below.

…or click any respelled word to hear it.

Green = exact, from the dictionary. Amber = approximate, from the rule-based fallback (mirrors rules_fallback.py). Homograph-blind by design — see the README for honest limits.

About the sound: the font only changes how text looks. The audio is separate — your browser's built-in speech voice (Web Speech API, free & offline-capable) speaking the original English. It is not part of the font.
